# 二维矩阵搜索动画说明

## 教学目标

让第一次接触算法的读者理解：矩阵每行、每列都递增，因此从右上角比较一次，就能安全排除一整行或一整列。

## 可观察状态

- 主结构：输入矩阵；每格使用稳定 ID `row:col` 和固定行列坐标。
- 当前状态：指针所在单元格、目标值、已检查格、已排除行/列。
- 代码状态：`AlgorithmStep.codeLines` 对应实现行；变量旁注显示 row、col、value、target。

## 关键帧规则

| operation | 焦点与画面变化 | 解说重点 |
| --- | --- | --- |
| init | 指针落在右上角 | 为什么从右上角开始 |
| eliminate_col | 当前格高亮，整列变暗，指针下一步左移 | 当前值大于目标，下面只会更大 |
| eliminate_row | 当前格高亮，整行变暗，指针下一步下移 | 当前值小于目标，左边只会更小 |
| match | 命中格变为绿色并保留 | 当前值等于目标，返回找到 |
| done | 显示搜索结束提示 | 指针越界意味着剩余候选已排除 |

## 固定视觉编码

- 黄色格 + 三角指针：正在比较；绿色格：命中；深色行/列：已排除；浅色圆点：已检查；描边格：目标值。
- 颜色之外同时使用指针、形状和图例文字；图例与检查/排除计数始终显示。
- 按稳定单元格 ID 做 D3 keyed join；坐标只由行列索引和 cellSize 决定。
- 每帧保留最近 144 个已检查位置，避免输入大矩阵时 DOM 无界增长。
- `prefers-reduced-motion` 下关闭 CSS 过渡，D3 位移时长归零。

## 人工复核要点

使用默认目标 5：右上角 15 大于 5，排除第 5 列；移至 11、7 并重复向左；到 4 小于 5，排除第 1 行并向下；到 5 命中。相邻步骤检查的只是焦点、排除方向和计数，矩阵位置保持稳定。
